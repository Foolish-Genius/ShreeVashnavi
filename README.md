# Shree Vaishnavi Software

Modern React/Vite website for SHREE VAISHNAVI SOFTWARE, Bareilly.

## Run locally

1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Included

- React + Vite app shell
- Framer Motion page and card animations
- Lucide icons
- Responsive mobile navigation
- Home, About, Products, and Contact routes
- Existing company and Tally assets reused from `assets/images`
- WhatsApp CTA, phone links, enquiry form, and Google Maps location link
